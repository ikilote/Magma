 API Reference

Selector — [mgCard3d]

Applies a CSS 3D tilt effect to the host element based on mouse cursor position. The perspective is set automatically on the parent element on hover.

When mgCard3dGlare is enabled, a two-layer holographic effect is added: an iridescent rainbow foil (color-dodge) whose hue rotates with the tilt angle, plus a specular streak band (overlay) that sweeps across the card.

Inputs

Input Type Default Description
mgCard3dMax number 15 Maximum tilt angle in degrees.
mgCard3dPerspective number 1000 CSS perspective distance (px) applied to the parent element on hover.
mgCard3dLerp number 0.12 Lerp speed while hovering (0.05–0.3). Lower = smoother, higher = more reactive.
mgCard3dReturnLerp number 0.05 Lerp speed when the pointer leaves. Lower = softer, slower return to rest.
mgCard3dScale number 1.05 Scale factor applied during hover.
mgCard3dGlare boolean false Enables the iridescent holographic foil + specular streak effect.
mgCard3dGlareMax number 0.6 Maximum foil intensity (0–1).
mgCard3dSheen boolean false Directional light band that sweeps across the card with the tilt angle, like a fixed light reflection.
mgCard3dLightAngle number 135 Direction the sheen light comes from, in degrees (135 = top-left).
mgCard3dSheenMax number 0.6 Maximum sheen intensity (0–1).

CSS custom property

Property Description
--mg-card3d-foil-colors Color-stop list for the repeating foil gradient. Defined globally in css-var.css. Override on any ancestor or directly on the card element to change the foil palette.
--mg-card3d-foil-texture background-image laid over the rainbow for the holographic grain (default: a fine glitter grid). Override with any gradient or url(...) for a custom sparkle texture.
--mg-card3d-foil-texture-size Tile size of the foil texture layer. Default 12px 12px.
--mg-card3d-mask Optional mask-image restricting all effects (glare, foil, sheen) to its opaque zones. Accepts any mask value, e.g. url('/art.png') or linear-gradient(#000 60%, transparent 60%). Unset = whole card.
--mg-card3d-mask-size Size of the mask image. Default 100% 100% (covers the whole card).
--mg-card3d-mask-position Position of the mask image. Default center.
--mg-card3d-mask-repeat Repeat behaviour of the mask image. Default no-repeat.
--mg-card3d-mask-mode How the mask is interpreted: alpha (default, uses transparency) or luminance (uses black/white).
--mg-card3d-glare-blend,
--mg-card3d-foil-blend,
--mg-card3d-sheen-blend 		mix-blend-mode of each layer. Defaults: color-dodge (glare, foil), overlay (sheen). Use soft-light for a subtler look.
--mg-card3d-glare-opacity,
--mg-card3d-foil-opacity,
--mg-card3d-sheen-opacity 		Max opacity of each layer at full intensity. Defaults: 1 / 0.85 / 0.9.
