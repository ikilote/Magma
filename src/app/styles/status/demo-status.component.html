Status indicators with a colored dot and optional text. Pure CSS — no Angular component needed. Uses the .status class with a theme modifier.

CSS Variables

Variable Default Description
--status-dot-size 8px Diameter of the dot
--status-dot-color currentColor Color of the dot (overridden by theme)
--status-gap 6px Space between dot and text
--status-color inherit Text color (overridden by theme)
--status-font-size 0.85em Font size
