API Reference

Selector — [limitFocus]

exportAs: 'limitFocus'. Traps keyboard focus within the host element: Tab and Shift+Tab cycle through focusable children only. Focus returns to the origin element on destroy. Hidden or tabindex="-1" elements are automatically excluded. A MutationObserver keeps the list up to date.

Method Return Description
focus() void Gives focus to the child with the lowest limitFocusFirst value

Selector — [limitFocusFirst]

Marks a focusable child as a priority focus target. When limit.focus() is called, the element with the lowest numeric value gets focus.

Input Type Description
limitFocusFirst (required) number | undefined Priority value — lower = focused first
