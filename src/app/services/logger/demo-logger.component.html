API Reference

Service — Logger

Thin injectable wrapper around the browser console. Adds a static minimum log level filter (Logger.minLogLevel) and an optional prefix (Logger.suffix) applied to every message.

Static properties

Property Type Default Description
Logger.minLogLevel keyof typeof LoggerLevel 'info' Messages whose level is strictly below this value are silently dropped.
Logger.suffix string '' String prepended to every logged message.

Methods

Method Signature Description
log (value: string, level?: LoggerLevel, ...extra: unknown[]) => void Log with an explicit level. Default level: LoggerLevel.log.
info (value: string, ...extra: unknown[]) => void Shorthand for LoggerLevel.info → console.info.
debug (value: string, ...extra: unknown[]) => void Shorthand for LoggerLevel.debug → console.debug.
warn (value: string, ...extra: unknown[]) => void Shorthand for LoggerLevel.warn → console.warn.
error (value: string, ...extra: unknown[]) => void Shorthand for LoggerLevel.error → console.error.
