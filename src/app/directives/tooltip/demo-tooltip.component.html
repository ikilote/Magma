API Reference

Selector — [mgTooltip]

Shows a tooltip in a CDK Overlay on hover. Sets aria-describedby on the host for accessibility. Cleans up the overlay on mouse leave or component destroy.

Inputs

Input Type Default Description
mgTooltip string '' Text displayed in the tooltip
mgTooltipEntryDelay number 200 Delay in ms before the tooltip appears on hover
mgTooltipDisplayDelay number 0 Duration in ms the tooltip stays visible (0 = infinite)
mgTooltipDescribedBy string | undefined — Custom id for aria-describedby. Auto-generated if not set.
