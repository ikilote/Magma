 API Reference

Inputs — mg-menubar

Input Type Default Description
menus MagmaMenuDef[] [] JSON mode: list of top-level menu definitions. Ignored when tag-mode mg-menu children are present.
ariaLabel string 'Application menu' Accessible label for the role="menubar" element.

Outputs — mg-menubar

Output Type Description
menuItemExecuted MagmaMenuItemDef Emitted after any item action is invoked.

Keyboard navigation

Key Context Behavior
← / → Focus on a menu trigger Move to the previous / next top-level menu trigger, skipping separators.
← / → Inside an open dropdown ← closes the current sub-menu (if open) or navigates to the previous top-level menu. → opens the sub-menu of the focused item (if any) or navigates to the next top-level menu.
↑ / ↓ Inside an open dropdown Move through items. ↓ on a trigger opens the dropdown and focuses the first item.
Enter / Space Focused item Activate the item or open its sub-menu.
Escape Any level Close one level: sub-menu → parent item; top-level menu → trigger button.

Types — MagmaMenuDef

Field Type Description
label string? Top-level menu trigger label.
icon string? Icon shown before the label. Accepts a text character, emoji, ligature, or an image URL (http://…, /path/to/icon.png, relative paths with image extension).
items MagmaMenuItemDef[]? Items inside this menu.
separator boolean? Renders a vertical divider in the menubar instead of a menu trigger.

Types — MagmaMenuItemDef

Field Type Description
label string? Item label.
icon string? Icon shown before the label. Accepts a text character, emoji, ligature, or an image URL (http://…, /path/to/icon.png, relative paths with image extension).
action () => void Called when the item is activated.
separator boolean? Renders a horizontal divider instead of a clickable item.
disabled boolean? Prevents interaction.
children MagmaMenuItemDef[]? Nested sub-menu. Opens to the right of the parent item.
