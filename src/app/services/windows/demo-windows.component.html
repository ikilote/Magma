 API Reference

Service — MagmaWindows

Injectable service that opens Angular components in floating, draggable overlay windows. Windows are managed globally via CDK Overlay and a MagmaWindowsZone container.

Methods

Method Signature Description
openWindow (component: Type<unknown>, params?: MagmaWindowInitParams, focus?: boolean) => MagmaWindowInfos Opens a new window containing the given component. Returns the window info object.
removeWindow (window: MagmaWindowInfos) => void Closes and removes a window by its info object
removeWindowById (id: string) => void Closes and removes a window by its id
focusWindowById (id: string) => void Brings a window to the front
minimizeWindowById (id: string) => void Minimizes a window (hidden but still registered)
restoreWindowById (id: string) => void Restores a minimized window
getWindowPosition (id: string) => MagmaWindowPosition | null Returns the current { x, y } position of a window, or null
getWindowInstance (id: string) => MagmaWindow | null Returns the MagmaWindow component instance
getWindowData (id: string) => MagmaWindowInfos | null Returns the metadata object for a window

Properties

Property Type Description
windows MagmaWindowInfos[] All currently open windows
onAddWindow Subject<MagmaWindowInfos> Emits when a window is opened
onRemoveWindow Subject<string> Emits the id when a window is closed
onMinimizeWindow Subject<string> Emits the id when a window is minimized
onRestoreWindow Subject<string> Emits the id when a window is restored
onFocusWindow Subject<string> Emits the id when a window is focused

MagmaWindowInitParams — window configuration

Property Type Description
position 'default' | 'center' | { x: number; y: number } Initial position of the window
bar boolean Shows the title bar
barTitle string | Type<unknown> Title string or a component rendered in the bar
barButtons boolean Shows minimize / maximize / close buttons in the bar
width / minWidth / maxWidth / height / minHeight / maxHeight string CSS size constraints for the window
fixed boolean | 'top' | 'bottom' | 'left' | 'right' Fixes the window to an edge or disables dragging
over boolean Renders above all other windows (z-index bump)
inputs Record<string, unknown> Inputs forwarded to the hosted component

Creating window content — AbstractWindowComponent

Components hosted inside a window should extend AbstractWindowComponent.

Member Type Description
parent (required input) MagmaWindow Reference to the hosting window, injected automatically
close() void Closes the parent window
