Introduction

The scrollable directive provides animated scroll navigation between sections of a scrollable container.

It uses requestAnimationFrame for smooth, performant scrolling and stops on user wheel interaction.

Three directives work together: [mgScrollable] on the container, [mgScrollTarget] on sections, and [mgScrollGoto] on navigation buttons.

Features

  • Animated scroll with configurable speed
  • Interrupt on wheel interaction
  • Position tracking via outputs
  • Instant jump (non-animated) option
  • Keyboard accessible navigation (Enter/Space)
  • Sticky element offset via mgScrollableSticky

Usage

Place [mgScrollable] on a scrollable container (with overflow: auto and a fixed height).

Mark sections with [mgScrollTarget]="'sectionId'".

Create navigation buttons with [mgScrollGoto]="'sectionId'".

Inputs — [mgScrollable] (container)

Input Type Default Description
mgScrollable string | undefined — CSS selector for an external scroll container. Uses the host element if not set.
mgScrollableSticky string | undefined — CSS selector of a sticky element inside the container. Its height is subtracted from scroll offsets.
mgScrollableSpeedMax number 50 Maximum pixels scrolled per animation frame
mgScrollableReducer number 2 Easing divisor — higher values give a slower, smoother deceleration

Outputs — [mgScrollable]

Output Type Description
scrolled number Current scroll position (debounced 50ms)
scrolledTo number Target position emitted after scrollTo()
changedTo string Id of the target emitted after goTo()
clicked { position: string | number; action: 'goTo' | 'scrollTo' | 'jumpTo' } Emitted on every navigation action

Methods — [mgScrollable]

Method Signature Description
goTo (id: string, scrolling?: boolean) => void Animated scroll to a registered target (pass false to jump)
scrollTo (pos: number | 'top' | 'bottom') => void Animated scroll to an absolute position
jumpTo (pos: number) => void Instant (non-animated) scroll to an absolute position
position () => number Returns the current scrollTop of the targeted element
positionsTarget () => Map<string, MagmaScrollElementPosition> Returns position metadata for all registered targets

Inputs — [mgScrollTarget] (on section)

Input Type Description
mgScrollTarget (required) string Unique id used to register this element as a scroll target

Inputs — [mgScrollGoto] (on nav button)

Input Type Default Description
mgScrollGoto (required) string — Id of the [mgScrollTarget] to scroll to on click/enter/space
mgScrollJump boolean false If true, uses jumpTo (instant) instead of animated scroll
