 API Reference

Service — VisionTheme

Manages vision accessibility themes by toggling CSS classes on document.body. Provides both a reactive Signal and an RxJS Observable for the current theme.

Methods

Method Signature Description
set (key: VisionThemeType) => void Activates a theme exclusively. Use 'none' to reset.
add (key: VisionThemeType) => void Adds a theme to the active set (multiple mode)
toggle (key: VisionThemeType) => void Toggles a theme on/off in the active set
remove (key: VisionThemeType) => void Removes a theme from the active set
next () => void Cycles forward to the next theme in the list (wraps around)
previous () => void Cycles backward to the previous theme (wraps around)
clear () => void Removes all active themes, equivalent to set('none')
isActive (key: VisionThemeType) => boolean Returns whether a theme is currently active
current () => VisionThemeType Returns the current theme key (single mode)

Reactive state

Property Type Description
theme Signal<VisionThemeType> Current active theme as a Signal
activeThemes Signal<VisionThemeType[]> All currently active themes (multiple mode)
themeChange$ Observable<VisionThemeType> RxJS observable emitting on every theme change
activeThemesChange$ Observable<VisionThemeType[]> RxJS observable emitting the full active list on every change
