Inputs — mg-window

Input Type Default Description
position 'default' | 'center' | { x: number; y: number } — Initial position of the window
zoneSelector string — CSS selector for the drag-and-drop container zone
bar boolean — Shows the title bar
barTitle string — Title displayed in the bar
barButtons boolean — Shows minimize / maximize / close buttons in the title bar
width / minWidth / maxWidth string — CSS size constraints for the window width
height / minHeight / maxHeight string — CSS size constraints for the window height
fixed boolean | 'top' | 'bottom' | 'left' | 'right' — Fixes the window to an edge or disables dragging
over boolean — Renders the window above all others (z-index bump)
focus boolean — Brings the window to front on creation
id string — Custom identifier (auto-generated if omitted)

Model (two-way) — mg-window

Model Type Default Description
isOpen boolean false Controls the visibility of the window

Outputs — mg-window

Output Type Description
closed void Emitted when the window is closed
minimized void Emitted when the window is minimized
maximized void Emitted when the window is maximized / fullscreen
restored void Emitted when the window is restored from minimized/maximized
focused void Emitted when the window is focused

Methods — mg-window

Method Return Description
open() void Opens the window
close() void Closes the window and emits closed
minimize() void Minimizes the window
restore() void Restores from minimized or maximized state
change() void Toggles fullscreen
updatePosition() void Recalculates the window position
