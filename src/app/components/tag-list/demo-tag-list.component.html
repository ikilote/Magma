 API Reference

Inputs

Input Type Default Description
tags (string | MagmaTagItem)[] — Data-driven mode: provides tags as an array
proposals string[] [] Autocomplete suggestions for the inline input
readOnly boolean false Hides remove buttons and input
disabled boolean false Disables the component (form integration)
allowClick boolean false Enables tag click emission
hideInput boolean false Hides the inline input, use add() method instead
placeholder string '' Placeholder for the inline input
removeAriaLabel string 'Remove: %item' Aria-label format for remove button (%item replaced)
addAriaLabel string 'Add tag' Aria-label for the input

Outputs

Output Type Description
tagsChange string[] Emitted when the tag list changes (add/remove)
tagClick string Emitted when a tag is clicked (requires allowClick)

Methods

Method Return Description
add(tag: string | MagmaTagItem) boolean Programmatically adds a tag. Returns false if duplicate/empty/disabled.
remove(tag: string | MagmaTagItem) void Programmatically removes a tag.
