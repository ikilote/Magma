API Reference

Inputs — [sortable]

Input Type Default Description
sortable (required) T[] — The data array to sort. The array is sorted in-place.
sortableFilterInput HTMLInputElement | MagmaInputCommon | undefined — Bound to an input element. Filters the list as the user types.
sortableFilter (key: string, item: T, index: number) => boolean — Custom filter function. Called for each item with the current filter string.

Outputs — [sortable]

Output Type Description
sortableChange T[] Emitted after each sort or filter operation with the updated list

Inputs — [sortRule] (on th)

Input Type Default Description
sortRule MagmaSortRules — Sort rule for this column. Can be:
  • A string: 'path.to.attr', 'path:number:desc', multi: 'a:number,b:date'
  • An object: { type: 'string'|'number'|'date', attr: '...', init?: 'asc'|'desc' }
  • { type: 'none' } — column not sortable

CSS classes applied by [sortRule]

Class Condition
sort-asc Column is sorted ascending
sort-desc Column is sorted descending
sort-cell Column has type: 'none' (not sortable)
