mg-loader-block

Skeleton container with no inputs. Accepts mg-loader-tile children and arranges them in a flex row.

Inputs — mg-loader-tile

Input Type Default Description
size string — Shorthand for width / height. Use flex for a flexible dimension and 100% for full-width. Examples: '70px / 70px', 'flex / 40px', '100% / 20px'.
