Vision Theme

A component and service to switch between vision accessibility themes (protanopia, tritanopia, high contrast). Opens a dropdown to pick a theme.

 API Reference

Inputs — mg-vision-theme

Input Type Default Description
compact boolean false Show only the icon (true) or icon + label (false)
multiple boolean false Allow selecting multiple themes simultaneously (checkbox mode)
themes VisionThemeInfo[] Built-in 4 themes Custom list of themes. Use for i18n or to add/remove themes.
ariaLabel string 'Vision accessibility theme' ARIA label for the trigger button
listAriaLabel string 'Vision themes' ARIA label for the dropdown list
clearAllLabel string 'Clear all' Label for the "clear all" option in multiple mode

Outputs — mg-vision-theme

Output Type Description
themeChange VisionThemeType Emitted when the user selects a theme (single mode)
themesChange VisionThemeType[] Emitted with all active theme keys when selection changes (multiple mode)

Service — VisionTheme

Method Signature Description
set (key: VisionThemeType) => void Sets the active theme
next () => void Cycles to the next theme in the list
add (key: VisionThemeType) => void Adds a theme to the active set (multiple mode)
toggle (key: VisionThemeType) => void Toggles a theme in the active set
activeThemes Signal<VisionThemeType[]> Signal with the currently active theme keys
isActive (key: VisionThemeType) => boolean Returns whether a given theme is currently active
