Inputs — mg-paginate

Input Type Default Description
page number 1 Current page number
total number 0 Total number of items
size number 25 Items per page
base string — Base URL for page links. Page number is appended.
linkId string — Shared ID to synchronize multiple mg-paginate instances on the same page
start number 3 Number of pages shown at the start
middleStart number 3 Pages shown before the current page
middleEnd number 3 Pages shown after the current page
end number 3 Number of pages shown at the end
showTotal boolean false Shows the total item count
textTotal string 'Total %' Template for the total label. % is replaced with the total count.
textPage string 'Page %p / %t' %p = current page, %t = total pages
queryParams Record<string, unknown> {} Extra query params added to each page link
