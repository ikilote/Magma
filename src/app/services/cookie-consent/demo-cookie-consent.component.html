API Reference

Service — CookieConsent

Injectable service that shows a cookie consent banner via CDK Overlay. No template tag is needed — the banner is injected automatically.

Methods

Method Signature Description
init (config: CookieConsentConfig) => void Initialises consent. Shows the banner unless consent was already given (and forceOpen is false).
remove () => void Deletes the stored consent cookie

Signals

Signal Type Description
options Signal<CookieConsentOption[]> Current list of options with their accepted state
bannerVisible WritableSignal<boolean> Whether the banner overlay is currently visible
durationCookie Signal<number> Retention duration in days (default 365)

CookieConsentConfig

Property Type Default Description
options CookieConsentOption[] — List of cookie preference options
forceOpen boolean false Shows the banner even if consent was already given
policy { show: boolean; url: string } — Cookie policy link shown in the banner
position CookieBannerPosition bottom: 10px, left: 10px Banner position: top, bottom, left, right, centerHorizontally, centerVertically
bannerSize OverlaySizeConfig minHeight: 150, maxWidth: min(95vw, 800px) CDK Overlay size constraints for the banner
cookieDuration number 365 Cookie retention period in days
texts Partial<CookieConsentTexts> — Override default banner/dialog labels (title, acceptAll, refuseAll, managePreferences, dialogTitle, save, policyLink, …)

CookieConsentOption

Property Type Description
id string Unique identifier
label string Display name
description string Shown in the preferences dialog
accept boolean Initial accepted state
locked boolean If true, the user cannot change this option (always accepted)
onAccept () => void Callback executed when the option is accepted
onRefuse () => void Callback executed when the option is refused
