 API Reference

Selectors — mg-ellipsis-button / [mgEllipsisButton]

No inputs. Content children are mg-ellipsis-item and optionally mg-ellipsis-content.

Methods — mg-ellipsis-button

Method Return Description
open() void Opens the dropdown panel
close() void Closes the dropdown panel and restores focus to the trigger button

Child elements

Selector Output Description
mg-ellipsis-content — Optional — replaces the default ellipsis (⋯) trigger label
mg-ellipsis-item action: void A menu item. Emits action when clicked or activated via keyboard.
