Service — MagmaMessages

Inject MagmaMessages and call its methods to display toast notifications. No template element needed — the overlay is created automatically.

Method Signature Description
addMessage (message: MagmaMessageContent, options?: { type?: MagmaMessageType; time?: string }) => void Displays a toast. time defaults to '3s'.
removeMessage (message: MagmaMessageInfo) => void Removes a specific message from the queue
clearMessages () => void Removes all messages at once

Types

Type Values / Shape
MagmaMessageType 'info' | 'success' | 'warn' | 'error' | 'tip'
MagmaMessageContent string | { component: Type<unknown>; input?: Record<string, unknown> }
