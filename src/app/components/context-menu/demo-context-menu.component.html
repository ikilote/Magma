Inputs — [mgContextMenu] (directive)

Input Type Default Description
mgContextMenu ContextMenuData<T> — Menu configuration: contextMenu items array + optional data payload
mgContextMenuMode 'default' | 'bubble' 'default' default renders a list; bubble renders a circular layout
mgContextMenuDisabled boolean false Prevents the context menu from opening

Methods — MagmaContextMenu

Method Return Description
open(event, menuData?, mode?) boolean Opens the menu at the cursor position. Returns false if disabled or empty.
close(event?) void Closes the currently open context menu

ContextMenuData interface

Property Type Description
contextMenu ContextMenuItem[] Array of menu items
data T Optional payload passed to each item's action callback

ContextMenuItem interface

Property Type Description
label string Displayed label
iconText string Icon or emoji displayed beside the label
action (data: T) => void Callback executed when the item is clicked
component Type<AbstractContextMenuComponent> Alternative to label: renders a custom component inside the menu
inputs Record<string, unknown> Inputs forwarded to the custom component
