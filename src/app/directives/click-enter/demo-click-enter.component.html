 API Reference

Selector — [clickEnter]

Makes any element behave like a button: adds tabindex="0" and role="button", then listens for click and keydown.enter.

Inputs

Input Type Default Description
disabled boolean false Disables the click/enter interaction and removes tabindex and role

Outputs

Output Type Description
clickEnter KeyboardEvent | MouseEvent Emitted on mouse click or Enter keydown when not disabled
