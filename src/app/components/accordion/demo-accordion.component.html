API Reference

Container — mg-accordion

Wraps one or more mg-expansion-panel components. By default, only one panel can be open at a time. Add the multiple attribute to allow multiple panels open simultaneously.

Inputs — mg-accordion

Input Type Default Description
multiple boolean false When true, multiple panels can be open simultaneously. By default only one panel is open at a time.

For mg-expansion-panel inputs, outputs and child selectors, see the Expansion Panel page.
