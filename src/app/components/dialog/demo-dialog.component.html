Inputs — mg-dialog

Input Type Default Description
closeButton boolean false Shows a close button in the top-right corner
closeBackdrop boolean false Closes the dialog when clicking outside it
closeButtonTitle string 'Close' Tooltip / aria-label for the close button
title string — Visible title rendered at the top of the dialog
label string — ARIA label used when no visible title is present
id string — Custom id for the dialog element (auto-generated if omitted)

Outputs — mg-dialog

Output Type Description
closed void Emitted when the dialog is closed

Methods — mg-dialog

Method Return Description
open() void Opens the dialog
close() void Closes the dialog and emits closed
