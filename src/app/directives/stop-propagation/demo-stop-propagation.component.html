API Reference

Selector — [stopPropagation]

Enables event propagation blocking on the host element. Add companion boolean attributes (stopClick, stopKeydown) to choose which events to stop.

Inputs

Input Type Default Description
stopClick boolean false Calls stopPropagation() on click events
stopKeydown boolean false Calls stopPropagation() on keydown events
