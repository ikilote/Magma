API Reference

Selector — [mgDragScroll]

Lets the user scroll an overflowing element by grabbing its background and dragging, like panning a map or a board. The host element must be scrollable (e.g. overflow: auto).

A drag starts only when the pointer goes down on the element's own background, not on an interactive child (a, button, input, textarea, select, label, [draggable="true"], [contenteditable], or any element carrying data-no-drag-scroll). This keeps clicks on real content working while empty space becomes a scroll handle. Pointer capture keeps the drag alive even when the cursor leaves the element, and the click that ends a drag is swallowed so a grab over a link does not also trigger it.

Inputs

Input Type Default Description
mgDragScrollDisabled boolean false Disable the behavior without removing the directive.
mgDragScrollAxis 'both' | 'x' | 'y' 'both' Which axis can be panned.
mgDragScrollThreshold number 5 Pixels the pointer must travel before a press becomes a drag (below this, clicks still fire).
mgDragScrollCursor boolean false Show the grab / grabbing cursor on the host.
mgDragScrollIgnore string — CSS selector of zones that must not start a drag. A press on a matching element (or inside one) is left to the content, in addition to the built-in checks.

Outputs

Output Type Description
dragStart void Emitted when a drag actually starts (after the threshold is crossed).
dragEnd void Emitted when a drag ends.

Opting a child out

Two ways to make a zone non-draggable: add data-no-drag-scroll to the element itself, or pass a CSS selector to mgDragScrollIgnore to exclude zones without touching their markup (e.g. a custom slider or a drawing surface). Both apply on top of the automatic exclusion of interactive elements.
