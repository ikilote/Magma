API Reference

Service — MagmaPointerModeService

Root-level service that tracks whether the user is currently navigating by keyboard or by pointer (mouse / touch). Any keydown switches to keyboard mode; the next mousemove switches back to pointer mode. It is shared across the entire application and used internally by components such as mg-menubar.

Member Type Description
isKeyboard Signal<boolean> true after any keydown event. Resets to false on the next mousemove.
