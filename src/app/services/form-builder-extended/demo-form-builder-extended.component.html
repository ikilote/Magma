 API Reference

Service — FormBuilderExtended

Extends Angular's FormBuilder with inline validation message configuration and non-nullable controls by default. Works with standard Angular Reactive Forms.

Methods

Method Signature Description
groupWithError <T>(controls: T, options?) => FormGroup<FormMapperExtended<T>> Creates a strongly typed, non-nullable FormGroup. Each control is defined by a ParamsMessages config object that declares default, validators, and error messages. Existing AbstractControl instances (sub-groups, arrays) are passed through as-is.
validateForm (form: FormGroup | FormArray) => void Marks all controls as touched and calls updateValueAndValidity() recursively, triggering validation error display.
array <T extends AbstractControl>(controls: T[], opts?) => FormArray<T> Typed wrapper around FormBuilder.array()

ParamsMessages<T> — control configuration

Property Type Description
default T Initial value of the control
emptyOnInit boolean If true, initialises the control with undefined instead of default
options AbstractControlOptions Standard Angular control options (onlySelf, emitEvent, …)
control ParamsMessagesControl Validation rules with inline error messages (see below)

message string | ((params) => string)

Fallback error message shown when no per-validator message matched. Supports {token} interpolation. The token name is looked up in order: state → Angular's errorData → paramsData.

Each per-validator message property also supports the same tokens. (See next table)

Alternatively, pass a function (params) => string to build the message programmatically. The params object provides type, state, errorData, data, and params.

Validator Available tokens
minlength {minlength} — configured min (state) · {requiredLength} — same · {actualLength} — current length
maxlength {maxlength} — configured max (state) · {requiredLength} — same · {actualLength} — current length
min {min} — configured min (state) · {actual} — current value
max {max} — configured max (state) · {actual} — current value
pattern {pattern} — configured pattern (state) · {requiredPattern} — same · {actualValue} — current value
inlist {list} · {actualValue}
