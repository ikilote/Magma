Input

Generator Errors Alignment API Reference

Inputs — mg-input (container)

Input Type Default Description
id string — Custom id for the wrapper element (auto-generated if omitted)
typeValue 'default' | 'value' | 'array' 'default' How checkbox values are accumulated: single boolean, single value, or array
returnValue 'default' | 'value' | 'boolean' 'default' Shape of the value returned by checkbox/radio
alignMode 'row' | 'column' 'row' Layout direction for grouped checkboxes/radios

Shared inputs — all mg-input-* controls

These inputs are available on mg-input-text, mg-input-number, mg-input-textarea, mg-input-password, mg-input-checkbox, mg-input-radio, mg-input-select, mg-input-color, mg-input-date, mg-input-range.

Input Type Default Description
disabled boolean false Disables the control
readonly boolean false Makes the control read-only
placeholder string — Placeholder text (text, number, password, select, textarea)
placeholderAnimated string — Animated placeholder: '30 3 1500 |' — speed, repeats, interval, separator
datalist string[] | number[] — Predefined suggestions (text, number, color, range)

Shared outputs — all mg-input-* controls

Output Type Description
update T Emitted on confirmed change (blur / enter / selection)
valueChange T Emitted on every input event (real-time)

Specific inputs — mg-input-text

Input Type Default Description
maxlength number | undefined — Maximum character length
clearCross boolean false Shows a clear (×) button inside the field
clearLabel string 'Clear' ARIA label for the clear button
type 'text' | 'email' | 'url' | 'tel' 'text' Underlying HTML input type

Specific inputs — mg-input-number

Input Type Default Description
step number — Increment/decrement step for arrows and keyboard
min / max number — Minimum and maximum allowed values
forceMinMax boolean false Clamps value to min/max on every keystroke
noDecimal boolean false Prevents decimal values
noNegative boolean false Prevents negative values
formater string — Display format pattern, e.g. #,##0.00
showArrows boolean false Shows increment/decrement arrow buttons

Specific inputs — mg-input-checkbox

Input Type Default Description
value unknown — Value emitted when the checkbox is checked
checked boolean false Initial checked state
mode 'checkbox' | 'toggle' 'checkbox' Renders as a classic checkbox or a toggle switch

Specific inputs — mg-input-select

Input Type Default Description
data Select2Data [] Array of options ({ value, label } or groups)
multiple boolean false Allows selecting multiple options
overlay boolean false Opens the dropdown in a CDK overlay (useful inside scrollable containers)
nativeKeyboard boolean false Enables native select-style keyboard navigation
noResultMessage string — Message shown when no option matches the search

Child elements — mg-input

Selector Description
mg-input-label Visible label linked to the control
mg-input-desc Helper text below the control
mg-input-error Validation error message
mg-input-prefix Content placed inside the input, before the field
mg-input-suffix Content placed inside the input, after the field
mg-input-before Content placed outside the input wrapper, before it
mg-input-after Content placed outside the input wrapper, after it
