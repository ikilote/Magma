API Reference

Inputs — table[mg]

Input Type Default Description
hover boolean false Highlights hovered row and column simultaneously
hoverRow boolean false Highlights the entire hovered row
hoverCol boolean false Highlights the entire hovered column
hoverCell boolean false Highlights only the hovered cell

Inputs — thead[mg]

Input Type Default Description
sticky boolean false Makes the header row sticky while scrolling

Inputs — tr[mg]

Input Type Default Description
baseline boolean false Aligns cell content to baseline instead of middle

All other native elements (tbody, th, td) just need the mg attribute to receive the table styles.
