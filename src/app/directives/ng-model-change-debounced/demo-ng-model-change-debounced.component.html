API Reference

Selector — [ngModelChangeDebounced]

Adds a debounced version of (ngModelChange). Must be placed on the same element as [(ngModel)]. Skips the initial value and only emits when the value has changed.

Inputs

Input Type Default Description
ngModelChangeDebounceTime number 500 Debounce delay in milliseconds. Dynamically reactive — changing it resets the timer.

Outputs

Output Type Description
ngModelChangeDebounced T Emitted with the current value after the debounce delay, with deduplication
