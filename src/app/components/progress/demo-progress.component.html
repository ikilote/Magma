Inputs — mg-progress

Input Type Default Description
loaded number | undefined — Value already loaded / transferred
total number | undefined — Total value. Used to compute the progress bar percentage
displayFormat 'size' | 'percent' | 'raw' 'size' Controls how the progress text is formatted. size: file size via fileSize pipe. percent: shows loaded / total as a percentage. raw: shows raw numbers with an optional unit suffix.
unit string '' Unit label appended after the numbers when displayFormat is 'raw' (e.g. 'items', 'étapes').
numberFormatPattern string '#,###' Number pattern (NumFormatter) used when displayFormat is 'percent' or 'raw' (e.g. '#,###', '#,###.00').
numberFormatDecimalSymbol string '' Decimal separator symbol used when displayFormat is 'percent' or 'raw'. Empty keeps the default ('.').
numberFormatSeparator string '' Grouping (thousands) separator symbol used when displayFormat is 'percent' or 'raw' (e.g. '\u00A0' to display 1 000).
sizeFormat FileSizePipeParams — Options forwarded to the fileSize pipe when displayFormat is 'size'. Supports format, language, translate.
