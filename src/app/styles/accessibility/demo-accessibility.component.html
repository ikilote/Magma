How to use accessibility themes

Import the desired theme CSS file alongside css-var.css, then use the service or component.

Available theme files

  • theme-protanopia.css — Red-green color blindness (protanopia)
  • theme-deuteranopia.css — Red-green color blindness (deuteranopia)
  • theme-tritanopia.css — Blue-yellow color blindness
  • theme-achromatopsia.css — Complete color blindness (achromatopsia)
  • theme-high-contrast.css — Low vision / high contrast needs
