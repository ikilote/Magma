 API Reference

Directive — [mgPopover]

Attach to any element to make it a popover trigger. The popover content is a TemplateRef and can contain any interactive elements (buttons, forms, links…).

The template receives let-ctx context with a close() method to close the popover programmatically.

Inputs

Input Type Default Description
mgPopover TemplateRef required Template to render inside the popover panel.
mgPopoverPosition MagmaConnectedPosition 'bottom-start' Side relative to the trigger: top, bottom, left, right with optional -start / -end suffix.
mgPopoverTrigger 'click' | 'hover' 'click' What opens the popover.
mgPopoverOffset number 4 Gap in px between the trigger and the panel.
mgPopoverDisabled boolean false When true, the trigger is inert.

Template context

Variable Type Description
$implicit.close () => void Closes the popover from within the template (let-ctx).

Host bindings

Attribute Description
aria-expanded Reflects whether the popover is currently open.
aria-controls Points to the popover panel id.
