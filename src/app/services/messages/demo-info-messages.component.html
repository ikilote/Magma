Zones sharing the same position

Two zones registered with an identical position object share the same CDK overlay. Their messages appear in the same stack, grouped automatically.

API Reference

Service — MagmaMessages

Inject MagmaMessages and call its methods to display stacked toast notifications. No template element needed — overlays are created automatically via CDK.

Method Signature Description
addZone (id: string, config: MagmaMessageZoneConfig) => void Register a named display zone with a screen position. Zones with the same position share one overlay.
addMessage (message, options?: { type?, time?, zone? }) => void Display a toast. zone defaults to 'default' (bottom-right). time defaults to '3s'.
removeMessage (message: MagmaMessageInfo) => void Remove a specific message.
clearMessages () => void Remove all messages.
