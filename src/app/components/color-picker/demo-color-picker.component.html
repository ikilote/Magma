Inputs — mg-color-picker (component)

Input Type Default Description
color string | undefined '' Initial color value (any CSS color format)
alpha boolean false Enables the alpha channel slider
readonly boolean false Makes the picker read-only
clearButton boolean false Shows a clear button to reset the color
palette string[] | undefined — Custom color palette. Uses the built-in palette when undefined.
texts MagmaColorPickerTexts | undefined — Override UI labels (hsl, palette, cursorZoneLabel)
datalist string[] — Predefined values for the hex input datalist

Outputs — mg-color-picker

Output Type Description
colorChange string Emitted on every color change (hex value)

Inputs — [colorPicker] (directive)

Input Type Default Description
colorPicker string — Initial color value
colorPickerAlpha boolean false Enables the alpha channel
colorPickerDisabled boolean false Disables the picker overlay
colorPickerReadonly boolean false Makes the picker read-only
colorPickerClearButton boolean false Shows the clear button
colorPickerPalette string[] | undefined — Custom color palette
colorPickerTexts MagmaColorPickerTexts — Override UI labels
colorPickerDatalist string[] | undefined — Predefined values for the hex input datalist

Outputs — [colorPicker]

Output Type Description
colorChange string Emitted in real time as the user picks a color
colorClose string Emitted on overlay close, only if the color changed
