Inputs — mg-timeline

Input Type Default Description
direction 'horizontal' | 'vertical' 'horizontal' Layout direction. horizontal: time flows right, items are rows. vertical: time flows down, items are columns.
start number | string | Date — Explicit start of the time axis. Auto-computed from items if omitted.
end number | string | Date — Explicit end of the time axis. Auto-computed from items if omitted.
unit 'year' | 'month' | 'day' 'year' Granularity of the time axis ticks.
lang string — BCP-47 locale tag for tick labels (e.g. 'fr', 'en').
axisSize string '80px' Width (horizontal) or height (vertical) of the label column/row.
tickSize number 60 Size in px of each tick cell. Also drives --mg-timeline-tick-size. Used internally to compute the minGap fraction.
minGap number 10 Minimum visual gap in px between two items before they are placed on a separate track. Items closer than this threshold are treated as overlapping even if their exact positions do not touch.
showGrid boolean true Whether to show the grid lines aligned with each tick.
dragScroll boolean false Let the user pan the timeline by grabbing its background and dragging. The pan axis follows direction automatically (horizontal → x, vertical → y).

Outputs — mg-timeline

Output Type Description
itemClick MagmaTimelineClickEvent Emitted when an item bar is clicked. Not fired when the item has a link (the <a> handles navigation instead). The event contains label, contentHtml, start, end, color, link and the original MouseEvent.
annotationClick MagmaTimelineAnnotationClickEvent Emitted when an annotation flag is clicked. Not fired when the annotation has a link (the <a> handles navigation instead). The event contains label, contentHtml, start, color, link and the original MouseEvent.

Inputs — mg-timeline-item

Input Type Default Description
label string — Fallback label when no content is projected. If HTML content is projected inside <mg-timeline-item>, it takes priority over this input.
start number | string | Date — Start of the item on the time axis (required). Accepts a year number, an ISO date string (e.g. '2008-09-12'), or a Date object for sub-tick precision.
end number | string | Date — End of the item. If omitted, the item spans one tick.
color string — CSS color for the bar background. Overrides --mg-timeline-item-color.
link string — URL — wraps the bar in an <a> element.
linkTarget string '_self' Target attribute for the link.
disabled boolean false When true, suppresses the link interaction.

Inputs — mg-timeline-annotation

Input Type Default Description
label string — Fallback label when no content is projected. If HTML content is projected inside <mg-timeline-annotation>, it takes priority over this input.
start number | string | Date — Position of the annotation on the time axis (required). Accepts a year number, an ISO date string (e.g. '2008-09-12'), or a Date object. The annotation is rendered as a marker line at this exact position.
color string — CSS color for the annotation line and flag. Overrides --mg-timeline-annotation-color.
link string — URL — wraps the annotation flag in an <a> element.
linkTarget string '_self' Target attribute for the link.
disabled boolean false When true, suppresses the link interaction.
nowrap boolean true When true (default), the annotation flag label stays on a single line (white-space: nowrap). Set to false to let the text wrap — useful in vertical mode where the flag is constrained to the axis column width.
